What LiveMix does

Alpha software for operators who want to run a multi-camera production from a single machine.

Switch and compose

Cut, timed transitions, T-bar, stingers, eight overlay channels, layers, crop, chroma and luma key, 3D LUTs, and waveform, parade and vectorscope scopes.

Mix stereo audio

48 kHz capture and monitoring, Master, A and B buses, and per-input EQ, gate, compression, gain and delay.

Record and distribute

Four independently routed outputs to windows, DeckLink, NDI, OMT or SRT. Two recordings plus MultiCorder, and shared encoders for RTMP destinations.

Instant Replay

Mark events across up to eight camera angles, cue A/B players, build playlists and export clips.

Capture hardware

Webcams, capture cards, DeckLink, NDI and OMT. Pick the resolution, frame rate and video format the device reports, and attach the card's audio.

Teleprompter

A scrolling script with a reading line, mirror and flip for a prompter glass, text file import, and keyboard, MIDI and automation control.

Studio scenes

Web pages and presentations as inputs, and a Virtual Set with backdrop, presenter and foreground layers.

Control the show

Telestrator, keyboard and MIDI shortcuts, a local web switcher, scripts and VISCA PTZ over UDP.

Your language

Choose the interface language in Settings. English and Brazilian Portuguese are included, and the catalogs are plain JSON.

Help test it

LiveMix needs operators with real hardware as much as it needs developers.

  • Run a 30-minute rehearsal and report audio and video drift.
  • Test DeckLink, NDI, OMT or SRT on another machine, with the driver and signal you use.
  • Film a flash with two cameras to check Replay sync.
  • Translate the interface into your language.

Frequently asked questions

Which systems does LiveMix run on?

Windows x64 and Apple Silicon Macs. The two platforms have separate media backends; the setup guide lists what each one supports.

Does it need special hardware?

No. A webcam or the built-in test sources are enough to try it. DeckLink, NDI and OMT need their own drivers or runtimes.

Can I open presets from other switchers?

Partly. The import report lists missing media and unsupported input types.

Is it ready for a live show?

It is alpha software. Rehearse first, and check the roadmap for combinations that still need hardware testing.
